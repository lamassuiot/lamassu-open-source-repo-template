# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or
pull requests.**

Instead, please report vulnerabilities privately using
[GitHub Security Advisories](../../security/advisories/new) for this repository. This allows
maintainers to assess and address the issue before it is publicly disclosed.

If private security reporting is not enabled for this repository, please contact the
maintainers through a private channel before disclosing any details publicly.

When reporting, please avoid including:

* Credentials, tokens, or private keys
* Customer data or customer-identifiable information
* Confidential architecture or internal infrastructure details

Instead, describe the vulnerability, its potential impact, and steps to reproduce it
using non-sensitive, redacted examples.

## Responsible disclosure

We ask that you:

* Give us reasonable time to investigate and address a reported vulnerability before
  any public disclosure.
* Make a good faith effort to avoid privacy violations, data destruction, and service
  disruption while researching a vulnerability.
* Only interact with accounts or data you own, or with explicit permission.

We will acknowledge reports in a timely manner and keep you informed of remediation
progress.

## Scope

This policy covers the source code, configuration, and CI/CD workflows maintained in this
repository.
